# Luv2Liv Property Management Website

A modern, responsive, single-page static website for **Luv2Liv Property Management LLC**, an exclusive and personal property management company serving Northern Virginia.

## Tech Stack
- **HTML5**: Semantic layout and structure.
- **CSS3**: Custom design system, CSS Grid/Flexbox, smooth scroll animations.
- **Vanilla JavaScript**: Mobile hamburger menu functionality and scroll observers.
- **FormSubmit**: Backend-free form submission logic.

## Deployment
This website is completely static and ready to be hosted on **GitHub Pages** (or any other static host like Netlify/Vercel). 
No build step, node modules, or backend architecture is required. Simply push the repository and enable GitHub Pages on the `main` branch.
